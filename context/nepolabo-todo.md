# nepolabo-todo — プロジェクトコンテキスト

> 7セクション統一テンプレート

## What（何を作るか）

- シンプルなTODOアプリ
- 基本CRUD（作成・表示・更新・削除）から始める
- カテゴリ分け、期限管理を追加
- 将来的にGmail/Googleカレンダー連携を視野に入れる

## Why（なぜ作るか）

- ENSEMBLE CASTフレームワークのテスト用途
- シンプルに始めて段階的に拡張する方針
- チーム並行開発の検証

## Constraints（制約）

- 技術スタック: React + TypeScript + Vite + Tailwind CSS
- ローカルストレージで永続化（DB不要）
- シンプル優先。過剰な機能追加は避ける
- レース条件防止: 各キャストは専用ファイルにのみ書き込む
