# 脚本生成プロンプトテンプレート

> このテンプレートは `collect-materials.py` の出力と組み合わせて使用する。
> `{...}` のプレースホルダーは実行時に置換される。

---

あなたは映画の脚本家です。以下の開発ログを元に、
{movie_title} のキャラクターたちが
ソフトウェア開発に挑む物語の脚本を書いてください。

## ルール
- バグや障害 → 敵（スタンド攻撃、困難）として描写
- コンフリクト解決 → チームワークの見せ場
- レビュー指摘 → 仲間内の信頼と厳しさ
- デプロイ成功 → 勝利の瞬間
- 各キャラクターの口調・性格は persona.yaml に準拠
- 技術的な内容は比喩で表現（一般視聴者にもわかるように）
- ただし完全にファンタジーにせず、実際に何が起きたかは伝わるように

## 出力形式（YAML）

```yaml
episode: {phase_number}
title: "サブタイトル"
synopsis: "あらすじ（3行以内）"
scenes:
  - scene: 1
    title: "シーンタイトル"
    narration: "ナレーション（状況説明）"
    mood: "tense"  # シーンの雰囲気（tense / triumph / comedy / crisis）
    beats:
      - character: {slug}
        action: "ト書き（動作・表情）"
        dialogue: "台詞"
        dramatic: true  # クライマックスの決め台詞に付与（大きく表示される）
      - narration: "途中のナレーション"
  - scene: 2
    title: "シーンタイトル"
    narration: "ナレーション"
    mood: "triumph"
    beats:
      - character: {slug}
        action: "ト書き"
        dialogue: "台詞"
```

### フィールド詳細

#### `mood`（シーンレベル）
シーン全体の雰囲気を指定する。Theater v4ではmoodが以下すべてを駆動する:
- **スクリーングロー**: スクリーン外縁の発光色
- **セリフの入り方**: 各ビートのエントリーアニメーション
- **シーン転換スタイル**: 次シーンへの繋ぎ方
- **背景演出**: シーン全体の色調・エフェクト

| 値 | グロー | セリフの入り方 | 転換 | 使いどころ |
|----|--------|---------------|------|-----------|
| (省略/calm) | 金色 微弱 | ゆっくりフェード | フェード・トゥ・ブラック | 平穏、準備、静かな決意 |
| `tense` | 暗い赤 | バンッとカットイン | アイリスアウト（速い） | バグ発生、障害対応 |
| `triumph` | 明るい金 | 下からせり上がり | 金色リング付きアイリス | デプロイ成功、勝利 |
| `comedy` | 白 微弱 | ポンッと吹き出し登場 | クイックカット | 雑談、ボケ、日常 |
| `crisis` | 赤 脈動 | 画面を揺らしながら突入 | グリッチノイズ | 本番障害、重大バグ |

省略時は calm 扱い。1エピソードに全種類使う必要はないが、
**シーンのmood変化が映画的な緩急を生む**ため、意図的に使い分けること。

推奨パターン:
- 起: calm → 承: tense → 転: crisis → 結: triumph
- 日常シーン → comedy、クライマックス → crisis or triumph

#### `dramatic`（ビートレベル）
`dramatic: true` を付与した台詞は、Theater v4で**画面を完全支配するテイクオーバー演出**になる:
- 背景が暗転し、セリフだけが浮かび上がる
- フォントサイズが最大化（2.5rem）
- スケールインアニメーション + テキストグロー
- ビューポートスナップで画面中央に固定

1エピソードにつき2〜3箇所が目安。乱用すると効果が薄れる。
**最終シーンの最終ビートには自動的にdramatic扱い + 金色パルスが適用される。**

使いどころ:
- 敵（バグ）を倒す決定打の台詞
- チームの覚悟を示す名台詞
- エピソードの核心を突く一言

#### `action`（ビートレベル・ト書き）
v4ではト書き（action）は**背景レイヤー**に配置され、小さく控えめに表示される。
映画の字幕的な扱い。セリフの邪魔にならず、でも雰囲気は伝わる。
短く書くのがベスト（10文字程度が理想）。
